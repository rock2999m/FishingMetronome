# タイラバメトロノーム - Tirava Metronome

ルアー釣りの巻き速度をリール回転数（RPM）で制御するメトロノームWebアプリケーション。ボートタイラバなどの釣法に対応。

## 🎯 主な特徴

- **精密なタイミング制御**: Web Audio APIを使用したスケジューラベースのメトロノーム音生成
- **iOS対応バックグラウンド再生**: MediaStreamAudioDestination + Media Session APIで画面ロック中も音声継続
- **完全オフライン対応**: Service Workerキャッシング により電波なしの釣り場でも動作
- **バッテリー最適化**: OLED自発光による省電力UI、Wake Lock制御
- **プリセット保存**: localStorageで巻き速度設定を保存・呼び出し
- **船速対応**: ボートタイラバモードで手入力船速を加味した相対速度計算

## 📋 必要要件

- **対応ブラウザ**: Chrome/Edge 90+, Safari 15+, Firefox 88+
- **対応端末**: iOS 15.1+, Android 11+
- **接続**: 初回セットアップ時にインターネット接続が必要（PWA化・キャッシング用）

## 🚀 インストール

### ローカル開発

```bash

python -m http.server 8000

# またはNode.js
npx http-server
```

`http://localhost:8000` にアクセス

### PWA化（ホーム画面追加）

1. ブラウザで本アプリを開く
2. **iOS Safari**: 共有 → ホーム画面に追加
3. **Android Chrome**: メニュー → アプリをインストール

## 🎮 使い方

### 基本操作

| 機能 | 操作 |
|------|------|
| RPM調整 | スライダーをドラッグ或いは±5RPMボタン |
| 再生/停止 | 「再生」ボタン |
| ハンドル巻き取り量 | 入力欄に機種のスペック値を入力（cm） |
| 船速入力 | ボートタイラバの場合は船速をm/sで入力 |
| 目標速度 | (オプション) 計算用参考値として表示 |

### プリセット保存

1. 巻き速度などを調整
2. プリセット名を入力（例：「ハイピッチタイラバ用」）
3. 「保存」ボタンをクリック
4. 保存済みプリセットをクリックすると全設定を復元

## 📱 iOS Safari特有の注意

1. **マナーモード**: iOSのサイレントスイッチ有効時は無音になります（Web Audio仕様）
2. **ストレージ容量**: iOS 17以降は最大容量の60%まで使用可能
3. **初回セットアップ**: 出発前に一度アプリを開いてService Workerをインストール
4. **バックグラウンド制限**: PWAはネイティブアプリほどバックグラウンド実行時間は保証されません

## 🎵 オーディオ生成

### メトロノーム音

- **周波数**: 800 Hz（正弦波）
- **継続時間**: 100 ms
- **エンベロープ**: 即座立ち上げ → 指数減衰

## 📊 計算ロジック

### ルアー移動速度

```
ルアー移動速度 = (ハンドル巻き取り量 / 100 * RPM / 60) + 船速
                    ↑ cm→m変換   ↑ 回転→秒変換
```

### 例

- ハンドル巻き取り量: 75 cm
- RPM: 60
- 船速: 0.5 m/s

```
= (75 / 100 * 60 / 60) + 0.5
= (0.75 * 1) + 0.5
= 1.25 m/s
```

## 🔍 トラブルシューティング

### 音が出ない

| 症状 | 原因 | 対策 |
|------|------|------|
| iPhoneで音なし | マナーモード有効 | 本体のサイレントスイッチをOFF |
| 再生ボタンが反応しない | AudioContext未初期化 | 画面をタップして初期化 |
| ポケット中に音が聞こえない | 音量が小さい | スマホの音量キーで調整 |

### キャッシュ問題

古いバージョンが使われ続ける場合：

```javascript
// ブラウザコンソール
navigator.serviceWorker.getRegistrations()
    .then(registrations => {
        registrations.forEach(r => r.unregister());
    });
```

その後ページをリロード

### 計算がおかしい

1. ハンドル巻き取り量の単位がcmか確認
2. 船速がm/sか確認（ノット単位の場合は÷1.94）

## 🎓 設計原則

1. **Client-first**: サーバーに依存しない設計
2. **Battery-aware**: 釣行時間を念頭に
3. **Pocket-optimized**: ポケット中使用を前提
4. **Fail-safe**: 不具合時も基本機能は動作
